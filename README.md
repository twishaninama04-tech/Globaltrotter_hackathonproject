# 🌍 GlobeTrotter – Personalized Travel Planning Platform

Tagline: **"Plan Less. Explore More."**

GlobeTrotter is a full-stack, production-quality travel planning web application.

---

## 🚀 Quick Start

### 1. Run Backend Server
```powershell
cd backend
node src/server.js
```
Runs on `http://localhost:5000`

### 2. Run Frontend Web Application
```powershell
cd frontend
npm run dev
```
Runs on `http://localhost:3000`

## 🌟 Key Features
- **JWT Authentication & Protection**
- **Personalized Dashboard** with budget progress and upcoming trip cards
- **Multi-City Itinerary Builder** with Timeline, List, and Calendar views
- **City & Activity Discovery** with filters and single-click trip assignment
- **Financial Dashboard & Recharts Analytics** with budget over-budget alerts
- **Public Itinerary Sharing & One-Click Trip Cloning**
- **Admin Analytics Dashboard** for platform insights
